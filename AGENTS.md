# Repository release policy

- `huzaifah1530-bot/VixSrc` is the source-code repository. Do not create GitHub Releases or release tags here.
- `huzaifah1530-bot/Vela` is the release repository. Do not create, update, or delete releases there unless the user explicitly asks for that action.
- A source-code push or version bump is not authorization to publish a release. Desktop CI may build and upload workflow artifacts, but it must not publish a GitHub Release automatically.
